# jazz-influencia-ab
Projeto acadêmico sobre a influência do Jazz no A&amp;B (Arte e Branding)
#  Jazz & sua Influência no A&B

> Um projeto web que explora como o Jazz influenciou o universo do A&B (Arte, Branding e experiências visuais), destacando estilo, criatividade e identidade cultural.

---

##  Sobre o projeto

O Jazz não é apenas um gênero musical — é um movimento cultural que impactou profundamente áreas como design, publicidade, moda e identidade visual.

Este projeto apresenta, de forma interativa, como o Jazz influenciou o A&B através de:

- Expressão criativa  
- Improvisação no design  
- Estética visual única  
- Cultura e identidade artística  

---

##  Funcionalidades

-  Página inicial com introdução ao Jazz  
-  Seção de dicas e curiosidades  
-  Cards com conteúdos visuais  
-  Filtro de conteúdo (JavaScript)  
-  Tema escuro inspirado em clubes de Jazz  

---

##  Tecnologias utilizadas

- HTML  
- CSS3 (com foco em design moderno)  
- JavaScript  
- Git e GitHub  
- Sonar
- Cypress
---

##  Conceito visual

O design do projeto foi inspirado em:

-  Clubes de Jazz clássicos  
-  Estética noturna  
-  Cores contrastantes (preto, dourado, roxo, azul escuro)  
-  Elementos sofisticados e minimalistas
